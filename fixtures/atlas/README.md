# Hospital financial-assistance atlas (Massachusetts)

`ma.json` is the Massachusetts export of the **Waive atlas** — one procedure sheet per nonprofit hospital, every documented field carrying the exact quote from the hospital's own published policy and the dated source it came from.

- License: Creative Commons Attribution 4.0 International (see `LICENSE.md`).
- Attribution: "Waive atlas, CC BY 4.0, https://github.com/Fluffy-SHIBAINU/waive".
- Export generated 2026-10-22. Data only; no application code is shared with Waive.

Kindred Snap uses it for the financial-assistance step: when a bill names a hospital with a published sheet, the eligibility check quotes that hospital's own thresholds (for example Newton-Wellesley Hospital, CCN 220101: free care at or below 150% of the federal poverty guideline, 85% discount to 250%, 70% to 300%). The hospital remains a **demo partner**: the policy figures are real public record; the billing-office connection and every response from it are simulated and labelled as such.
