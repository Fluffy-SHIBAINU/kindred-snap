# Kindred Snap

**Lower your healthcare bills.** Snap the bill once, add household income once, and Kindred investigates, prepares the right request, asks for one approval, and tracks the case to a documented resolution.

A Kindred AI hackathon build. Fresh code; no application code copied from other Kindred products.

- **Project start:** 2026-11-09 10:40 KST (01:40 UTC)
- **Deadline:** 2026-11-09 14:30 KST (MVP + 90-second demo video)
- **Status:** planning and design (see `docs/PLAN.md` and `docs/mocks/`)

All patient data in this repository is synthetic. The hospital is a clearly labelled demo partner; hospital and Medicare connections are simulated adapters until real credentials and agreements exist.
